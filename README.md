# Machine Learning From Scratch

A collection of machine learning algorithms implemented from scratch using NumPy.

The goal of this project is to understand the internal mechanics of machine learning algorithms without relying on high-level ML libraries.

---

## Implemented Algorithms

• Linear Regression  
• Logistic Regression  
• Gradient Descent Optimization  

---

## Why This Project

Many ML applications rely on libraries such as scikit-learn or TensorFlow.

This project focuses on implementing core algorithms manually to understand:

- optimization
- gradient descent
- parameter learning
- model prediction

---

## Tech Stack

Python  
NumPy  

---

## Project Goal

To build a strong conceptual understanding of machine learning algorithms by implementing them from first principles.
